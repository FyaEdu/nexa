# Referensi tampilan

`prototype-nexa.html` adalah prototipe satu file berisi semua fitur NEXA (Tahap 1–5) dengan data contoh.
Buka langsung di browser (klik dua kali), lalu login memakai akun demo yang tertera.

Gunanya sebagai acuan tampilan dan alur saat mengerjakan tiap tahap. Ini bukan kode aplikasi:
datanya hanya tersimpan di browser, dan tombol unduh laporan tidak berfungsi di luar claude.ai.
Aplikasi yang sebenarnya ada di folder `backend` dan `frontend`.
